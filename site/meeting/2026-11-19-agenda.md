# SoS and Softplus runs

<div style="width: fit-content; margin: auto">

> [!note] SoS model
>
> Let $s$ be the attention score. The SoS model is given by
> $$
    h(s;x) = q_1^2(s;x)+q_2^2(s;x)
$$
> where $\text{deg}(q_1)=m/2$ and $\text{deg}(q_2)=m/2-1$.

</div> 

Let $z=\text{softplus}(s)$. We consider three models:

<div style="width: fit-content; margin: auto">

| Variant | Attention weight | Note |
|---|---|---|
| SoS | $h(s)$ |
| SoS + softplus | $h(z)$ |
| SoS + softplus prefactor | $z h(z)$ | Raises degree by 1

</div>




Intuition:
- Softplus: negative scores are first transformed into a small number *and then* fed into $h$. E.g., without it, $x^2$ would treat $-100$ and $100$ equally.
- Softplus prefactor: we additionally get the property that $\text{weight}\to0$ as $s\to-\infty$.


![](media/20261119-110704-d9f5fa.png)



<div style="width: fit-content; margin: auto">

> [!tip] Observations:
> - Query SoS + softplus prefactor performed best.
> - Sigmoid and Softplus baselines performed poorly.

</div>

# Poly diagnostics


### L2 normalization

<div style="width: fit-content; margin: auto">

> [!note] L2 Normalization
> RMSNorm on the activations, ignoring the learned scaling, effectively keeps the vector at magnitude $\sqrt{d}$. For the coefficients, we compute $\text{tanh}(w^\top x)$, which can saturate. Hence, here we try L2 normalization instead.

</div> 


![](media/20261119-103505-ba9fd8.png)


![](media/20261119-104255-a4749d.png)


<div style="width: fit-content; margin: auto">

> [!tip] Observations:
> - L2 normalization removed saturation, but didn't improve performance.
> - **Note:** even with saturation, input dependence can act like a sign switch.

</div> 


### Input dependence

<div style="width: fit-content; margin: auto">

> [!note] Calibration-mean intervention
> - Compute the average coefficients of each head based on a calibration set.
> - Fix the poly to these coefficients on every head.
> - Evaluate the model on a validation set.

</div> 

<div style="width: fit-content; margin: auto">

| Model | Calibration means |
|---|---:|
| query | 15.736 (+1.37%) |
| SoS | 15.602 (+1.25%) |
| SoS + softplus + prefactor | 15.463 (+1.21%) |

</div> 

<div style="width: fit-content; margin: auto">

> [!tip] Observations:
> - Removing input dependence clearly degraded performance.

</div>

# Small head-dimension
> When the head-dimension is small, the attention matrix is low-rank. Intuitively, this reduces the expressive power of the attention mechanism.

> [!note] Thoughts
> Maybe with large enough key dimension, exp already gets enough input dependence via the score. However, when we scale up, the key dimension typically stays fixed, in which case maybe a poly model can make better use of the limited input dependence. 

This motivates testing on small key dimensions at our 200M scale. Maybe with small key dimension, the model needs a more expressive activation than exp.

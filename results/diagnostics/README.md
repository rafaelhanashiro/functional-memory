# Diagnostics

Closed records of training behavior: what happened, measured on runs that live in their
study. A diagnostic answers a question about the runs, not about which mechanism is
better, so it has no open decision and enters no canonical comparison. Each topic holds
a short README, a pinned selection, and figures that regenerate from it; see
[AGENTS.md](../../AGENTS.md).
